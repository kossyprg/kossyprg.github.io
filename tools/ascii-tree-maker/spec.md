# ASCII ツリーメーカー 仕様書

## 1. 概要

インデントで階層を表したテキスト入力を、ASCII ツリー形式に変換するブラウザツール。変換はリアルタイムに行われ、結果はプレビュー表示される。

---

## 2. 機能要件

### 2.1 入力

- ユーザーは画面左側のテキストボックスに、インデントで階層を表したテキストを入力する
- 各行の先頭に **スペース** を付けることで階層の深さを表現する
- 1レベルあたりのインデント幅は入力テキストから自動検出する
  - 入力テキスト内に存在する非ゼロのインデント量（スペース数）の最小値を 1 レベル分として扱う
- タブ文字（`\t`）は自動的にスペース 4 つに変換してから処理する
- テキストボックスが空のとき、入力を促すプレースホルダーを薄く表示する
  - プレースホルダー文字列（例）：
    ```
    階層をスペースのインデントで表してください。
    例：
    usr
     bin
     lib
     local
      bin
      lib
    home
     alice
      Documents
      Downloads
     bob
    ```

### 2.2 オプション

| オプション | デフォルト | 選択肢 |
| --- | --- | --- |
| 枝の長さ | 2 | 0 / 1 / 2 / 3 / 4 |

- コンボボックス（`<select>`）から選択する
- 選択した瞬間に出力をリアルタイムで更新する

### 2.3 変換ロジック

#### 2.3.1 深さの計算

- 各行の先頭スペース数をインデント単位で割った値（小数点以下切り捨て）を深さ（depth）とする
- 深さ 0 の行をルートノードとして扱う

#### 2.3.2 ツリーの構築

- 深さ 0 のルートノードには接続文字を付けず、そのまま出力する
- 深さ 1 以上の各ノードについて「同じ親を持つ兄弟の中で最後の子か否か」を判定し、接続文字を選択する
  - 最後の子でない：`├` + `─` × 枝の長さ + ` `
  - 最後の子　　　：`└` + `─` × 枝の長さ + ` `
- 各ノードの左側に、祖先ごとの「最後の子か否か」に応じたプレフィックスを 1 レベルあたり 4 文字で付ける
  - 祖先が最後の子でない：`│   `（縦線 + スペース 3 つ）
  - 祖先が最後の子　　　：`    `（スペース 4 つ）
- 連続するルートノードはそれぞれ独立したツリーとして扱われる

#### 2.3.3 空行の扱い

- 入力中の空行は無視する（出力には含めない）

#### 2.3.4 レベルスキップへの対応

- 深さが飛んでいる場合（例：深さ 0 → 2）、中間ノードが存在しないものとして処理する（エラーにしない）

### 2.4 変換例

#### 2.4.1 枝の長さ = 2（デフォルト）

入力：
```
1
 1-1
  1-1-1
  1-1-2
 1-2
2
 2-1
 2-2
  2-2-1
  2-2-2
 2-3
```

出力：
```
1
├── 1-1
│   ├── 1-1-1
│   └── 1-1-2
└── 1-2
2
├── 2-1
├── 2-2
│   ├── 2-2-1
│   └── 2-2-2
└── 2-3
```

#### 2.4.2 枝の長さ = 0

出力（同じ入力）：
```
1
├ 1-1
│   ├ 1-1-1
│   └ 1-1-2
└ 1-2
2
├ 2-1
├ 2-2
│   ├ 2-2-1
│   └ 2-2-2
└ 2-3
```

#### 2.4.3 枝の長さ = 4

出力（同じ入力）：
```
1
├──── 1-1
│   ├──── 1-1-1
│   └──── 1-1-2
└──── 1-2
2
├──── 2-1
├──── 2-2
│   ├──── 2-2-1
│   └──── 2-2-2
└──── 2-3
```

#### 2.4.4 スペース 2 つ = 1 レベル

入力：
```
root
  child1
    grandchild1
  child2
```

出力（枝の長さ = 2）：
```
root
├── child1
│   └── grandchild1
└── child2
```

### 2.5 出力

- 入力テキストの変更に応じてリアルタイムにプレビューを更新する
- 枝の長さの変更に応じてリアルタイムにプレビューを更新する
- 変換結果を画面右側のプレビュー用テキストボックス（readonly）に表示する
- 「クリップボードにコピー」ボタンで変換結果をクリップボードへコピーする
- コピー完了後、ボタンのラベルを一時的に「コピーしました！」に変えてフィードバックを示す

---

## 3. 非機能要件

- サーバーサイドの処理は不要。すべてブラウザ上の JavaScript で完結する
- 対応ブラウザ：Clipboard API をサポートする主要モダンブラウザ（Chrome / Edge / Firefox / Safari 最新版）
- 入力が空の場合はコピーボタンを非活性にする

---

## 4. UI 構成

```
+----------------------------------------------------+
|  ASCII ツリーメーカー                               |
|  [枝の長さ: 2 ▼]                                   |
+-------------------------+--------------------------+
|  入力                   |  プレビュー（変換後）      |
|  [テキストボックス]      |  [テキストボックス]        |
|  (編集可・placeholder)  |  (readonly)              |
|                         |  [クリップボードにコピー]  |
+-------------------------+--------------------------+
```

- コンボボックス（枝の長さ）はタイトル下に配置
- 左右のテキストボックスは横並び（2カラムレイアウト）
- コピーボタンはプレビューエリアの下に配置
- ダークテーマを基調としたデザイン（ポートフォリオ全体と統一）
