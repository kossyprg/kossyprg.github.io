# Excel → Markdown テーブル変換ツール 仕様書

## 1. 概要

Excel やスプレッドシートからコピーしたタブ区切りテキストを、Markdown 形式のテーブルに変換するブラウザツール。変換結果はプレビュー表示されると同時にクリップボードへコピーされる。

---

## 2. 機能要件

### 2.1 入力

- ユーザーは画面左側のテキストボックスに、Excel / スプレッドシートからコピーした内容を貼り付ける
- 入力データはタブ文字（`\t`）を列区切り、改行（`\n`）を行区切りとするタブ区切りテキスト
- 例：`Name\tAge\nAlice\t30\nBob\t25`

### 2.2 オプション

| オプション | デフォルト | 選択肢 |
| --- | --- | --- |
| 先頭行をヘッダとして扱う | ON | ON / OFF |
| セル内改行の変換方法 | `<br>` | `<br>` / スペース |

### 2.3 変換ロジック

#### 2.3.1 セルの前処理

- 各セル値の先頭・末尾の空白文字（スペース等）をトリムする
- Excel からコピーした TSV では、セル内に改行を含むセルがダブルクォート（`"`）で囲まれる。このクォートを除去したうえで以降の処理を行う

#### 2.3.2 ヘッダの扱い

- **先頭行をヘッダとして扱う（デフォルト）**：入力の1行目をヘッダ行、2行目以降をデータ行とする
- **先頭行をヘッダとして扱わない**：空セルのみからなるヘッダ行をデータの先頭に自動挿入し、入力の全行をデータ行として扱う

#### 2.3.3 テーブル構造

- ヘッダ行の直下にセパレータ行（`| --- | --- | ...`）を挿入する。セパレータは `---` 固定
- 各セルは前後にスペースを挟み `| セル値 |` 形式で出力する
- 空セルは単一スペース（` `）でパディングし `|   |` とする
- 行ごとの列数が異なる場合、最大列数に合わせて不足列を空セルで補う

#### 2.3.4 エスケープ・改行変換

- セル値に含まれるパイプ文字（`|`）は `\|` にエスケープする
- セル内改行はオプションに従い変換する
  - `<br>`（デフォルト）：`<br>` タグに置換
  - スペース：半角スペース（` `）に置換

#### 2.3.5 出力形式

- 行区切りは LF（`\n`）に統一する
- 入力が空の場合は変換を行わない

---

### 2.4 変換例

#### 2.4.1 基本

入力：
```
Name\tAge
Alice\t30
Bob\t25
```

出力：
```
| Name | Age |
| --- | --- |
| Alice | 30 |
| Bob | 25 |
```

#### 2.4.2 空セルのパディング

入力：
```
A\tB
1\t2
3
```

出力：
```
| A | B |
| --- | --- |
| 1 | 2 |
| 3 |   |
```

#### 2.4.3 `|` エスケープ

入力：
```
A\tB
x|y\t2
```

出力：
```
| A | B |
| --- | --- |
| x\|y | 2 |
```

#### 2.4.4 セル内改行 → `<br>`（デフォルト）

入力（Excel コピー時の形式）：
```
A\tB
"line1\nline2"\t2
```

出力：
```
| A | B |
| --- | --- |
| line1<br>line2 | 2 |
```

#### 2.4.5 先頭行をヘッダとして扱わない

入力（セル値の前後スペースはトリムされる）：
```
A\tB
 1 \t 2 
3\t4
```

出力（空のヘッダ行が自動挿入される）：
```
|   |   |
| --- | --- |
| A | B |
| 1 | 2 |
| 3 | 4 |
```

---

### 2.5 出力

- 変換結果を画面右側のプレビュー用テキストボックス（readonly）に表示する
- 同時に変換結果をクリップボードへコピーする
- クリップボードコピー完了後、ボタンのラベルを一時的に「コピーしました！」に変えてフィードバックを示す

---

## 3. 非機能要件

- サーバーサイドの処理は不要。すべてブラウザ上の JavaScript で完結する
- 対応ブラウザ：Clipboard API をサポートする主要モダンブラウザ（Chrome / Edge / Firefox / Safari 最新版）
- 入力が空の場合はボタンを非活性にするかエラー表示を行う

---

## 4. UI 構成

```
+----------------------------------------------------+
|  Excel → Markdown                                  |
|  [☑ 先頭行をヘッダとして扱う]  [セル内改行: <br> ▼] |
+-------------------------+--------------------------+
|  入力                   |  プレビュー（変換後）      |
|  [テキストボックス]      |  [テキストボックス]        |
|  (編集可)               |  (readonly)              |
+-------------------------+--------------------------+
|         [変換してクリップボードにコピー]              |
+----------------------------------------------------+
```

- 左右のテキストボックスは横並び（2カラムレイアウト）
- オプション（チェックボックス・セレクトボックス）はタイトル下に配置
- ボタンは左右のテキストボックスの下中央に配置
- ダークテーマを基調としたデザイン（ポートフォリオ全体と統一）
